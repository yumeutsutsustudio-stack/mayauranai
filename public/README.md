# マヤ暦占い

生年月日から、マヤ暦の KIN・太陽の紋章・銀河の音・ウェイブスペルを調べたり、
2人の相性や人生年表を見たりできる占いです。
ブラウザで使える Web 版と、ターミナルで使える Python 版があります。

## Web 版

ブラウザで次のページを開くと、すぐに占えます（インストール不要）。

https://＜ユーザー名＞.github.io/＜リポジトリ名＞/

## ターミナル版を作った理由

もともと Web ページ（`index.html`）としてマヤ暦占いを作っていました。
これを Python だけで動く形にしておくと、

- ブラウザを開かなくても、ターミナルからすぐに占える
- 計算の仕組みが Python のコードとして読めるので、勉強や確認に使いやすい
- 追加のインストールが要らないので、Python があればどのパソコンでも動く

という良さがあるため、ターミナル版として作り直しました。
KIN の計算方法は Web 版とまったく同じです（2月29日は2月28日として扱い、うるう日を数えない方式）。

## 必要なもの

- Python 3.7 以上（標準機能だけを使っています。`pip install` は不要です）

## 使い方

フォルダの中で次のように実行します。

```
python maya.py
```

起動するとメニューが出るので、番号を入力して選びます。

```
＊＊＊ マヤ暦占い ＊＊＊
  1. 自分のKINを調べる
  2. 相性占い
  3. 人生年表
  4. 終了
番号を選んでください（1〜4）：
```

| 番号 | できること |
| --- | --- |
| 1 | 生年月日から KIN・太陽の紋章・銀河の音・ウェイブスペルを表示 |
| 2 | 2人の生年月日から相性（総合・恋愛・友人・仕事・家族）と関係のタイプ、ふたりのKIN を表示 |
| 3 | 誕生日から1年ごとの KIN（年回り）を、生まれた年から今年の3年先まで一覧表示 |
| 4 | 終了 |

### 生年月日の入力

`1990/05/20` のように **年/月/日** の形で入力します。
形がちがう、存在しない日付（例：2023/02/30）、1900年より前や未来の日付の場合は、
メッセージが出てもう一度入力できます。

### 文字の色

紋章の色（赤・白・青・黄）ごとに文字の色を変えて表示します。
Windows のターミナル（Windows Terminal、コマンドプロンプト、PowerShell）でも色が出るようにしています。
色が要らないときは、環境変数 `NO_COLOR` を設定すると色なしで表示されます。
